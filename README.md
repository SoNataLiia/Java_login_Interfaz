# PRIMER SIMULACRO DI

## Descripción

Este proyecto contiene una simulación de un sistema de login de la Universidad Europea implementado :


* Java (JavaFX)

El objetivo es practicar el desarrollo de interfaces y lógica básica de autenticación.

---

## Estructura del proyecto





### 🔹  universidad_europea_login_java (Java)

Aplicación desarrollada en Java con JavaFX.

Contiene:

* `HelloApplication.java` → clase principal
* `HelloController.java` → controlador
* `hello-view.fxml` → interfaz gráfica
* `pom.xml` → configuración Maven

---

## Funcionalidad

* Simulación de inicio de sesión
* Interfaz gráfica básica
* Separación entre lógica y vista

---

## Tecnologías utilizadas


* Java
* JavaFX
* Maven

---

## Objetivo del ejercicio

* Practicar estructura de proyectos
* Trabajar con interfaces gráficas
* Comprender separación MVC (Modelo-Vista-Controlador)

---

## Conclusión

El proyecto permite comparar la implementación de una misma funcionalidad en distintos lenguajes y entornos, reforzando conceptos básicos de desarrollo.
